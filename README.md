# Lexicon

English vocabulary trainer: 1000 B1–B2 words, Russian translations, IPA, contextual exercises and spaced repetition.

Website: https://vertigozz.github.io/lexicon-english/

These are the website files. Learning data is stored locally for guests and in a private Supabase account after sign-in. Personal progress, passwords, database credentials and service keys are never stored in this repository. The publishable project identifier in cloud-config.js is public; row-level security protects learning records.
